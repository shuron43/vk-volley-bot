# Актуальная документация VK Volleyball Bot

`docs/` содержит действующие знания, правила и инструкции. Полный список также
находится в корневом [AGENTS.md](../AGENTS.md), видимом агенту в каждой сессии.
При изменении состава документации оба списка обновляются вместе.

## Процесс разработки

| Документ | Содержание |
|---|---|
| [DEVELOPMENT.md](DEVELOPMENT.md) | Порядок разработки, актуальные знания и история, временная инлайн-память |
| [mode-piecemeal-growth.md](mode-piecemeal-growth.md) | Проектирование из текущих требований и наблюдаемых ограничений |
| [focused-specs.md](focused-specs.md) | Минимальные исполняемые спеки на границе продукта и их ревью |

Оба руководства обязательны перед разработкой; остальные документы выбираются
по текущей задаче. Приложение должно соответствовать действующим BDD.

## Начало работы

Для изменения поведения прочитать руководства разработки, затем выбрать
контракты из `BOT_COMMANDS.md`, `ARCHITECTURE.md` и `API_REFERENCE.md` и проверить
результат по `TESTING.md`. Для запуска выбрать `CONFIGURATION.md` и подходящую
инструкцию деплоя.

Исторические эксперименты, postmortem и завершённые RFC хранятся в `records/`.
Они не входят в список актуального знания и не читаются при обычном старте
сессии. Обращаться к ним следует только по запросу пользователя или при явной
необходимости исторических данных для текущей задачи.
