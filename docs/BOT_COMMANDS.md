# Команды бота

Бот реагирует на текстовые сообщения в групповом чате VK.

## Краткая справка

| Команда | Описание | Требует имя? |
|---------|----------|--------------|
| `+` или `записаться` | Записать себя | Нет |
| `-` или `отписаться` | Убрать себя | Нет |
| `+ Имя` | Записать друга | Да |
| `- Имя` | Убрать друга | Да |
| `список` / `участники` / `кто идёт` | Показать участников | Нет |
| `?` / `help` / `помощь` / `команды` | Показать справку | Нет |

## Подробное описание

### Записаться (+)

**Синтаксис:**
```
+
записаться
```

**Что происходит:**
1. Бот определяет ваш vk_id из сообщения
2. Запрашивает ваше имя через VK API (users.get)
3. Добавляет вас в хранилище как UserEntry

**Ответы бота:**
- Ты записался! — при успешной записи
- Ты уже в списке. — если вы уже записаны

**Особенности:**
- Имя берётся из VK (first_name). Если VK API вернёт пустой ответ или first_name отсутствует — будет Unknown. Ошибки сети/токена пробрасываются как исключения.
- Повторная запись невозможна (проверка по vk_id).

### Отписаться (-)

**Синтаксис:**
```
-
отписаться
```

**Что происходит:**
1. Бот ищет ваш vk_id в хранилище
2. Удаляет запись, если найдена

**Ответы бота:**
- Ты отписался. — при успехе
- Тебя не было в списке. — если вы не были записаны

### Записать друга (+ Имя)

**Синтаксис:**
```
+ Андрей
+  Мария  (лишние пробелы обрезаются)
```

**Что происходит:**
1. Бот извлекает текст после символа +
2. Убирает ведущие и конечные пробелы
3. Добавляет запись типа FriendEntry (без vk_id)

**Ответы бота:**
- {имя} записан(а) как друг. — при успехе
- Укажи имя друга: + Имя — если после + пусто

**Особенности:**
- Дубликаты допускаются — можно записать двух друзей с одинаковым именем.
- Регистр сохраняется как есть.
- Имя друга не валидируется — принимается любая непустая строка.

### Убрать друга (- Имя)

**Синтаксис:**
```
- Андрей
```

**Что происходит:**
1. Бот извлекает текст после -
2. Ищет первое точное совпадение по имени среди FriendEntry
3. Удаляет найденную запись

**Ответы бота:**
- {имя} убран(а) из списка. — при успехе
- Такого друга не нашлось. — если имя не найдено

**Особенности:**
- Удаляется только первое совпадение. Если два друга с одинаковым именем — нужно вызвать команду дважды.
- Сравнение точное (case-sensitive). `- андрей` и `- Андрей` — разные строки.

### Список участников

**Синтаксис:**
```
список
участники
кто идёт
```

**Что происходит:**
1. Бот читает текущий список из хранилища
2. Формирует нумерованный список

**Формат ответа:**
```
Список участников:
1. Алексей
2. Мария
3. Андрей (друг)
```

**Ответ если пусто:**
- Пока никто не записался.

### Помощь

**Синтаксис:**
```
?
help
помощь
команды
```

**Ответ бота:**
```
Команды:
+ или записаться — записаться
- или отписаться — отписаться
+ Имя — записать друга
- Имя — убрать друга
список — кто идёт
? — помощь
```

## Примеры диалога

### Сценарий 1: запись и просмотр списка

```
Алексей: +
Бот: Ты записался!

Мария: +
Бот: Ты записался!

Дмитрий: список
Бот:
Список участников:
1. Алексей
2. Мария
```

### Сценарий 2: запись друга

```
Алексей: + Андрей
Бот: Андрей записан(а) как друг.

Мария: список
Бот:
Список участников:
1. Алексей
2. Андрей (друг)
```

### Сценарий 3: отписка

```
Алексей: -
Бот: Ты отписался.

Мария: список
Бот:
Список участников:
1. Андрей (друг)
```

### Сценарий 4: попытка повторной записи

```
Алексей: +
Бот: Ты записался!

Алексей: +
Бот: Ты уже в списке.
```

## Inline-клавиатура

Каждый ответ бота сопровождается inline-клавиатурой:

```
➕    ➖
📋 Список   ❓ Помощь
```

### Кнопки

| Кнопка | Действие | Эквивалент |
|--------|----------|------------|
| ➕ | Записать себя | `+` |
| ➖ | Отписаться | `-` |
| 📋 Список | Показать участников | `список` |
| ❓ Помощь | Показать справку | `?` |

### Как работают callback-кнопки

1. Пользователь нажимает кнопку в VK
2. VK отправляет событие `message_event` боту (без текстового сообщения в чат)
3. Бот обрабатывает событие и:
   - Для `+` / `-` — показывает всплывающее уведомление (snackbar)
   - Для `📋` / `❓` — отправляет новое сообщение с результатом
4. Другие участники чата **не видят** нажатие кнопки

> **Ограничение:** Запись друга (`+ Имя`) через inline-кнопку невозможна, так как требует ввода имени. Используйте текстовую команду.

## Автоматический анонс

Раз в неделю (в заданный день и время) бот автоматически:
1. Очищает список участников
2. Отправляет сообщение с inline-клавиатурой:

```
🏐 Сбор на волейбол!
Кто идёт? Напиши + или имя друга через +
список — посмотреть участников
```

После анонса список начинает формироваться заново.

## Автоматическое напоминание

В заданный день и время (независимо от дня сбора) бот автоматически отправляет напоминание:

```
🏐 Напоминаем: сбор на волейбол!

Список участников:
1. Алексей
2. Мария
3. Андрей (друг)
```

Напоминание **не очищает** список — оно только показывает текущее состояние записи. Настраивается через `REMIND_ENABLED`, `REMIND_WEEKDAY` и `REMIND_TIME`.

## Ограничения MVP

- Нет лимита участников
- Нет админ-команд
- Нет статистики по посещаемости
