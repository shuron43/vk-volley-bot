# Исторические записи

Здесь хранятся отчёты экспериментов, postmortem и завершённые или отменённые RFC.
Это свидетельства того, что было известно и проверено в конкретный момент.
Действующие знания и инструкции находятся в [docs](../docs/README.md).

Агент не читает и не ищет записи при обычном старте сессии. Обращение допустимо
по запросу пользователя или когда для текущей задачи явно нужны исторические
данные: воспроизведение прежнего сбоя, результаты эксперимента или обоснование
решения, которого нет в актуальной документации. Сначала определяется вопрос,
затем открывается конкретная запись.

Старые планы не становятся текущими задачами. Имена функций, команды, результаты
проверок и выводы в записи относятся к её дате; при рефакторинге их не обновляют.
Новый эксперимент или изменившийся вывод оформляется новой записью. При переносе
допустимо исправить относительные ссылки и добавить отметку об архивном статусе.
Устойчивое знание из записи переносится в соответствующий документ `docs/`.
